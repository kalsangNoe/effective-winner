In this blog entry I want to go over a lecture given by Clayton Christensen. He talks about how small companies topple big companies, the 3 different types of innovation, and how those innovation types influence the economy. 

# The 3 types of innovation 
Christensen classifies innovation into 3 broad groups. 
1. The first type makes a very expensive, inaccessible service or product affordable and accessible. 
2. The second type improves over an existing value proposition by making it more efficient. 
3. And lastly, the third type of innovation makes an existing product or service cheaper. 

# Type 1. Big Leaps 
The first type of innovation is the quintessential archetype of innovation. Its the jump from mainframes to personal computers, from blackberry to iphone, typewriter to word processor. 

This innovation creates a lot of jobs but it is very costly as well. 


## Type 2. Incremental Leaps 
This type focuses on making an existing product better. The perfect example is the iPhone. Each year apple provides a new iPhone by adding new features, making the battery, camera better.  You are not creating a whole new product but you are making an existing product better to use. 

This innovation is focused more on sustainability. 

# Type 3. Downscaling Leaps 
This type focuses on making an existing product cheaper. It doesn't promise the latest and greatest features. It doesn't promise to revolutionize the world but it promises to make a value proposition available to the bottom of the market. Using the apple example again, this would be  iphone -> ipod touch --though the ipod touch has been discontinued--. 

This innovation if focused more on capital gains.

The interesting observation Christensen makes in his lecture is that these three types work sequentially in a circular mechanism.
